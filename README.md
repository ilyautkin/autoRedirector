## autoRedirector

autoRedirector — это дополнение для MODX CMS, которое позволит вам не беспокоиться о том, что иногда адреса страниц меняются. После установки плагин будет отслеживать изменение адресов страниц и записывать старые адреса в отдельную табличку. Если пользователь перейдет по одной из старых ссылок, плагин перенаправит его на актуальный адрес (HTTP 301 Moved Permanently). В результате пользователь увидит искомую страничку, а не ошибку 404.

Любое автоматически созданное правило редиректа можно отредактировать вручную или удалить.

### Возможности

- Автоматическое создание правил редиректа при изменении URI страниц
- Ручное управление правилами через интерфейс в панели администратора
- Поддержка GET-параметров и кириллических URL
- Работа с несколькими контекстами MODX
- Корректная обработка сортировки ресурсов (drag-and-drop)
- Пакетное удаление правил

### Как это работает

1. При сохранении страницы плагин перехватывает события `OnBeforeDocFormSave` и `OnDocFormSave`
2. Если URI страницы изменился, старый адрес записывается в таблицу `ar_rules`
3. При обращении к несуществующему URL плагин перехватывает событие `OnPageNotFound`
4. Если в таблице правил найден совпадающий URI, выполняется 301-редирект на актуальную страницу

### Требования

- MODX CMS
- PHP 5.6+ (совместимость с PHP 8)
- MySQL

### Структура проекта

```
_build/                                  — скрипты сборки transport-пакета
core/components/autoredirector/
├── elements/plugins/                    — основной плагин (обработка событий MODX)
├── model/                               — ORM-модель таблицы ar_rules (xPDO)
├── processors/mgr/                      — CRUD-процессоры для правил редиректов
├── controllers/                         — контроллеры админ-панели
└── lexicon/                             — переводы (en, ru, cs)
assets/components/autoredirector/
├── js/mgr/                              — ExtJS-интерфейс управления правилами
├── css/mgr/                             — стили
└── connector.php                        — точка входа для AJAX-запросов
```

### Технологии

| Слой | Технологии |
|------|-----------|
| Backend | PHP, MODX CMS, xPDO |
| Frontend | ExtJS 3.x, AJAX |
| БД | MySQL (таблица `ar_rules`) |
